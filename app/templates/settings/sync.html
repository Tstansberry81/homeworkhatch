Brightspace, Blackboard, Moodle and Schoology each give you a private calendar link. Grades, files and announcements don't come through a calendar link. Keep the link private: anyone who has it can see your school calendar.

Where do I find my calendar link?

Brightspace (D2L): open Calendar → Settings, tick Enable Calendar Feeds and save. Back in the calendar, click Subscribe, choose All Calendars and Tasks and copy the link.

Blackboard: open Calendar → Calendar Settings → the ⋯ menu → Share Calendar and copy the link. Older Blackboard pages call it Get External Calendar Link, at the bottom of the calendar.

Moodle: open the Calendar, click Import or export calendars at the bottom → Export calendar. Choose All events and Recent and next 60 days (or a custom range, if offered), click Get calendar URL, then Copy URL. The link stops working when you change your Moodle password; add it again then.

Schoology: open Account Settings (the arrow next to your name), find Share your Schoology calendar, click Enable and copy the iCal link. Some schools show it under Calendar → Export instead.

Each school can rename or turn off these options. If you can't find it, search your school's help pages for "calendar feed" or "subscribe to calendar".

Install the extension

  1. Open Homework Hatch on the Chrome Web Store and click Add to Chrome → Add extension. It works in Google Chrome 109 or newer on Chromebooks, Windows and Mac.
  2. School Chromebook or school Google account? If the button is greyed out or says it's blocked by your administrator, your school only allows extensions it has approved. Ask your school's IT to allow Homework Hatch, or use a personal Google account.
Can't use the Chrome Web Store? Install it from a zip

Not possible on a school-managed Chromebook (check chrome://management): those block extensions loaded from a zip too. A copy from the zip doesn't update itself; download the zip again for new versions.

Download .zip

Chromebook

  1. Open the Files app → Downloads. Right-click (two-finger tap) homework-hatch-extension.zip → Extract all. Don't just double-click it: that only opens it as a temporary drive, and the extension disappears after a restart.
  2. Keep the extracted folder in My files (not Google Drive) and don't delete it.
  3. Go to chrome://extensions, turn on Developer mode (top right), click Load unpacked, select the extracted homework-hatch-extension folder (the one with manifest.json inside) and click Open.

Windows

  1. In File Explorer → Downloads, right-click homework-hatch-extension.zip → Extract All → Extract. Move the extracted folder somewhere you'll keep it, like Documents.
  2. Go to chrome://extensions, turn on Developer mode (top right), click Load unpacked, select the homework-hatch-extension folder (the one with manifest.json inside) and click Select Folder.
  3. If Chrome says Manifest file is missing, you picked the wrong folder: pick the one that has manifest.json directly inside.

Then: pin it from the puzzle-piece menu, open your school's Canvas, click the Homework Hatch icon → Agree and connect. It opens this page and links itself to your account while you're signed in here; nothing to copy or paste.

Link it by hand instead

In the extension's Settings, the server is {{ server_url }} ; paste a server token from the box on the right, click Save, then Sync now.

Once set up it syncs every hour while Chrome is open: new files, grades and announcements, and never a file it already has. Hidden tabs, locked files and outside tools (WebAssign, Gradescope…) can't be read.
