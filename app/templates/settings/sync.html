Add to Chrome Open Canvas

Set it up by hand (Edge, Brave, Arc, or without the Chrome Web Store)
  1. Download the extension. Download .zip
    Unzip it somewhere you'll keep it (e.g. your Documents folder).
  2. Load it: go to chrome://extensions, turn on Developer mode, click Load unpacked, and pick the unzipped folder.
  3. Connect your school: open your Canvas in a tab, click the Homework Hatch icon, then Connect.
  4. Link it to your account: in the extension's Settings, the server is {{ server_url }} ; paste a server token from the box on the right. Then click Sync now.

Once set up it syncs every hour while Chrome is open: new files, grades and announcements, and never a file it already has. Hidden tabs, locked files and outside tools (WebAssign, Gradescope…) can't be read.
